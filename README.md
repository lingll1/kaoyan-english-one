# 考研英语（一）逐词精读生成器

把一份考研英语真题，生成一份适合精读的单文件网页：正文逐段拆开、每个单词上方标音标与本句词义、段下给语法点、题目逐词标注并配四段式解析，还带点击朗读与倍速。

这个仓库开源的是**生成这套文档的脚本、数据格式规范，以及一整篇可运行的样例**（2021 英语一 · 阅读 Text 1）。克隆下来就能跑，不需要真题以外的任何素材。

## 生成出来是什么样

一篇文档由六块组成，从上到下：

1. **页头**——年份、篇目、主题、题号、词数、难度标签，外加目录锚点。
2. **正文逐段**——一段一个卡片。每个词上方两行小字：上面是英式音标，下面是「词性 + 本句词义」。行距拉开，词与词之间留白，保证注释不打架。
3. **段意**——该段中文译文。
4. **本段语法点**——每条按「结构 / 考点 / 例」三行写，各占一段。
5. **真题原题**——题干与 A–D 选项同样逐词标注，选项下方给中文整句译文；题目下方是固定四段式解析：**原句含义 → 语法辨析 → 难点解析 → 易错点解析**。
6. **6 道同类型变体**——题型与真题错开，解析格式相同。

右下角七个圆钮：`音` 音标开关、`义` 词义开关、`注` 全部注释开关、`中` 字号、**倍速**、`读` 词朗读开关、`↑` 回顶。

每句开头有一个小麦克风，点它朗读整句（正在读的词会高亮）；点任意单词朗读该词。倍速按钮：单击 `1x → 0.5x → 0.25x → 1x` 循环，长按 0.5 秒切 `2x`（橙底），`2x` 下再单击回 `1x`。

生成结果是**零依赖的单文件 HTML**，双击就能看，也能直接打印。

## 环境要求

| 项目 | 要求 | 说明 |
|---|---|---|
| Python | 3.9 及以上 | 只用标准库，没有 pip 依赖 |
| 中文字体 | 系统自带即可 | 排版用宋体/思源宋体系列回退 |
| 浏览器 | 任意现代浏览器 | 朗读用浏览器自带 `speechSynthesis`，不调第三方服务 |
| 操作系统 | Windows / macOS / Linux | 脚本本身跨平台；朗读语音取决于系统装了哪些语音包 |

**不需要联网、不需要安装任何 Python 包。** 唯一例外是朗读：本机英文语音多半是「在线」语音，断网时英文朗读不可用（详见 [manual/01-环境说明.md](manual/01-环境说明.md)）。

## 快速开始

```bash
git clone https://github.com/<your-name>/kaoyan-english-one.git
cd kaoyan-english-one

python build.py 2021 1      # 生成样例这一篇
```

输出：

```
[2021 · 1]
  词数 387 / 校验 通过
  → 2021/docs/英语一2021_阅读Text1.html
```

用浏览器打开 `2021/docs/英语一2021_阅读Text1.html` 即可。

再跑一遍四道校验，确认环境没问题：

```bash
python verify.py 2021 1    # 逐词 token 拼回原文，与 SOURCE.md 比对
python qc.py     2021 1    # 题目区：每题的块是否齐、块名对不对、词序列是否一致
python _final.py 2021      # 成品结构计数 + 硬编码错误扫描
python _allcheck.py 2021   # 按 data/*.lesson.json 逐个核对产物体例
```

四条的预期输出分别是「全部一致。」「全部通过。」「全部检查通过。」「全部 1 篇结构核验通过。」

想一次生成某一年全部篇目：`python build.py 2021`。想生成总入口页：`python _rootindex.py`。

## 仓库结构

```
kaoyan-english-one/
├── build.py            排版引擎：读数据 → 出 HTML（核心，1200 余行）
├── verify.py           原文一致性校验（抓漏词/多词/拼写走样）
├── qc.py               题目区自检（不依赖 build.py）
├── _final.py           成品结构核验 + 硬编码扫描
├── _allcheck.py        按数据文件逐个核对产物体例（不要求固定篇数）
├── _rootindex.py       生成跨年份总入口页
├── _docx2source.py     把整卷 docx 转成 SOURCE.md 骨架
├── _fillans.py         把答案与参考译文填回 SOURCE.md 占位符
├── SPEC.md             正文区数据规格（words.txt / lesson.json）
├── SPEC-QUIZ.md        题目区数据规格（quiz.txt）
├── SPEC-OTHER.md       完形 / 新题型 / 翻译三种题型的数据差异
├── manual/             五篇说明文档（见下）
└── 2021/               ★ 完整样例：2021 英语一 · 阅读 Text 1
    ├── SOURCE.md           唯一文本来源（正文 + 题干 + 选项 + 答案）
    ├── data/
    │   ├── text1.words.txt     正文逐词标注
    │   ├── text1.quiz.txt      题干与选项逐词标注
    │   └── text1.lesson.json   段意、语法点、题目、解析、词汇表
    └── docs/
        └── 英语一2021_阅读Text1.html    ← 构建产物
```

一篇文档对应**四个数据文件**（三个 `data/` 下的输入 + 一份 `docs/` 下的产物），加一个唯一的文本来源 `SOURCE.md`。数据怎么填，见 [manual/02-数据格式.md](manual/02-数据格式.md)。

## 以一篇为例

[manual/03-以一篇为例.md](manual/03-以一篇为例.md) 把样例这一篇从头到尾拆开讲：四个文件各自长什么样、`build.py` 拿到它们之后做了哪几步、一段话是怎样一步步变成 HTML 的。**如果你只想照做一篇，看这一篇就够了。**

要点先说在前面：

- `SOURCE.md` 是**唯一**的文本来源，其他三个文件都必须与它逐字对齐，`verify.py` 和 `qc.py` 就是拿来卡这条的。
- `words.txt` 里**标点也占一个 token**（音标与释义写 `_`），这样 `verify.py` 才能把 token 拼回原句。
- 每道题（真题 + 变体）在 `quiz.txt` 里占 5 个块：`@stem:21` 加 `@opt:21:A/B/C/D`，每块末行以 `~` 开头写中文整句译文。

## 支持的题型

一套脚本覆盖考研英语一的四种题型，靠 `lesson.json` 的 `meta.part` 分派：

| `meta.part` | 题型 | 数据文件名 | 题量 | 选项 |
|---|---|---|---|---|
| `A` | 阅读理解 Text 1–4 | `text1`–`text4` | 5 题 | A–D |
| `cloze` | 完形填空 | `cloze` | 20 空 | A–D |
| `B` | 新题型 Part B | `partb` | 5 题 | A–H，视题型而定 |
| `C` | 翻译 Part C | `trans` | 5 句 | 无选项，`answer` 存参考译文 |

新题型还有一处特殊处理：正文**按正确答案顺序拼成一篇连续文章**，原空位号与选项收进段头右侧的小徽章（如「第 41 空 · 原选项 B」），人物匹配题则显示「第 41 题 · 答案 E」。这样正文读起来是通篇，不用先做题再回头拼。

细节见 [SPEC-OTHER.md](SPEC-OTHER.md)。
