# 01 · 环境说明

## 1. Python

脚本按 Python **3.9+** 编写，实际开发与测试环境是 **Python 3.12.10 / Windows 11 / Microsoft Edge**。

用到的都是标准库：`pathlib`、`json`、`re`、`html`、`sys`、`argparse`（部分脚本）。没有 `requirements.txt`，因为核心链路确实不需要装东西。

**唯一的例外是 `_docx2source.py`**，它用 `python-docx` 读 Word 文件：

```bash
pip install python-docx
```

这个脚本只在「手上是整卷 docx、要先转成 SOURCE.md 骨架」时才用得到。如果你已经有整理好的 `SOURCE.md`，它是可跳过的——样例仓库里就带了现成的 `SOURCE.md`，所以你刚才跑的四道校验一次都没用到它。

| 脚本 | 第三方依赖 |
|---|---|
| `build.py` `verify.py` `qc.py` `_final.py` `_allcheck.py` `_rootindex.py` `_fillans.py` | 无 |
| `_docx2source.py` | `python-docx` |

## 2. 浏览器与控制台

- **看文档**：任意现代浏览器。生成的是单文件 HTML，样式与脚本全部内联，没有外部资源，可以直接拷给别人或离线打开。
- **打印**：内置 `@media print`，A4 竖排时注释字号会自适应缩小。浏览器里按 `Ctrl+P` 预览即可。
- **控制台编码**：脚本输出里有 `✓`、`→` 这类字符。Windows 控制台默认是 GBK（cp936），`✓` 不在 GBK 里，直接打印会抛 `UnicodeEncodeError`。所以八个脚本开头都插了一段保护：

  ```python
  import sys as _sys
  try:
      _sys.stdout.reconfigure(encoding="utf-8", errors="replace")
      _sys.stderr.reconfigure(encoding="utf-8", errors="replace")
  except Exception:
      pass
  ```

  这段是有实际来历的：早期 `verify.py` 在 GBK 控制台下跑 `python verify.py 2021 1`，只要一打 `✓ 一致` 就崩。加上保护后，控制台即便设成 GBK 也能正常输出（不可编码的字符按 `replace` 降级）。

## 3. 朗读功能

朗读用的是浏览器原生 `speechSynthesis`，**不联网调用任何第三方服务**，也不需要 API key。但「不联网」不等于「离线可用」——要看系统里装了哪些语音。

在一台 Windows 11 + Edge 的机器上实测：

| 指标 | 实测值 |
|---|---|
| 语音总数 | 325 |
| 英文语音 | 47 |
| 其中**本地**英文语音 | **0** |
| 中文语音 | 17（其中 3 个本地） |

也就是说，那 47 个英文语音（`Microsoft Libby / Ryan / Sonia / Thomas … Online (Natural)`）**全部是「在线」语音**，需要联网才能出声。脚本的选音逻辑是「优先本地，其次自然度与口音打分」，本机因为没有本地英文语音，实际会选中 `Microsoft Libby Online (Natural) - English (United Kingdom)`。

**断网时会发生什么**：英文朗读没有声音，中文不受影响。想离线用，在 Windows「设置 → 时间和语言 → 语言」里为 English 添加语音包（几十 MB），装好后脚本会自动改用本地语音，不用改代码。

另外两个绕不开的限制，值得先说清楚：

1. **IPA 音标字符无法被语音引擎朗读**。点音标实际读的是单词拼写，不是那串音标符号。想听标准音还是得靠真人录音词典。
2. **同形异音词单点可能读错**。`record`、`present`、`use` 这类词，脱离句子时引擎只能猜一个读音；整句朗读因为带了上下文，反而更准。

## 4. 字体

排版用系统字体回退，不引入任何 webfont（否则就不能单文件离线了）：

```
正文中文：宋体 / 思源宋体 / Songti SC
等宽部分：Consolas / SF Mono
```

字号通过 CSS 变量控制，`--tx` 是英文词大小、`--an` 是注释大小、`--rowgap` 是行距。右下角「中」圆钮可以在小/中/大三档间切换，改动只作用于当前页面，不写回文件。
